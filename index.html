RTF

Darstellung

Trainingsziel

Mit Datum wird rückwärts geplant (Grundlage → Aufbau → Spitze → Tapering). Ohne Datum gilt die Planlänge; „FTP steigern“ endet mit einer Testwoche. Der Plan startet immer an einem Montag.

Eigene Schwerpunkte (optional)

Gewählte Einheiten ersetzen in Aufbau- und Spitzenphase die Vorgaben des Zieltyps, bei „Individuell“ im ganzen Plan.

Profil & Zeit

Trainingstage

Tag aktivieren, maximale Dauer und Uhrzeit festlegen; „lang“ markiert den Tag für die lange Einheit.

Noch kein Plan

Kalender-Automatik

RTF legt die Einheiten der nächsten 14 Tage automatisch in freie Zeitfenster deines iPhone-Kalenders: Uhrzeit verschieben, bei wenig Zeit kürzen, sonst auf einen freien Tag derselben Woche legen. Intensive Einheiten bekommen die besten Fenster. Danach wird der Plan automatisch an intervals.icu, Zwift und Garmin gesendet.

Letzte Anpassungen

Kurzbefehl einrichten

Einmalig in der App „Kurzbefehle“. Übertragen werden nur Beginn und Ende deiner Termine – keine Titel, Orte oder Teilnehmer. Ganztägige Termine ignoriert RTF.

  1. Kurzbefehle öffnen → + → Name RTF Kalender.
  2. Aktion Kalenderereignisse suchen hinzufügen. Filter: Startdatum · liegt in den nächsten · 14 Tage. Sortieren nach Startdatum, Limit aus.
  3. Aktion Wiederholen mit jedem hinzufügen (Eingabe: Kalenderereignisse).
  4. Innerhalb der Wiederholung Aktion Text mit Inhalt: Wiederholungsobjekt.Startdatum | Wiederholungsobjekt.Enddatum. Bei beiden Datumsvariablen antippen → Datumsformat ISO 8601, Zeit einbeziehen an.
  5. Nach Ende der Wiederholung: Aktion Text kombinieren (Wiederholungsergebnisse) mit Neue Zeilen.
  6. Aktion Inhalt von URL abrufen: URL https://intervals.icu/api/v1/athlete/0/events · Methode POST · Header Authorization = Wert unten · Anfragetext JSON mit den Textfeldern: category = NOTE, start_date_local = 2000-01-01T00:00:00, name = RTF Kalender, description = Kombinierter Text.
  7. Tab Automation → + → Tageszeit 05:00, täglich → Sofort ausführen → Kurzbefehl RTF Kalender. Optional eine zweite Automation um 12:00.

Enthält deinen intervals.icu-Schlüssel – nicht weitergeben. Nach dem ersten Lauf des Kurzbefehls hier auf „Jetzt prüfen“ tippen.

intervals.icu (empfohlen)

Liest Fitness, Ermüdung und FTP aus intervals.icu (dort Garmin, Zwift bzw. Strava verbinden) und überträgt den Plan in deinen intervals.icu-Kalender. Von dort gehen die Einheiten automatisch an Zwift.

So richtest du es ein
  1. Kostenlos bei intervals.icu anmelden.
  2. Unter Settings → Connections Garmin und Zwift verbinden (bei Zwift das Hochladen geplanter Workouts aktivieren).
  3. Unter Settings → Developer Settings einen API-Key erzeugen und hier eintragen.

Strava

Einmalig unter strava.com/settings/api eine API-Anwendung anlegen, als Authorization Callback Domain eintragen und Client-ID und Secret hier speichern. Die Zugangsdaten bleiben nur auf diesem Gerät.

Ohne Verbindung

Zwift & Kalender über intervals.icu

Überträgt alle kommenden Einheiten in deinen intervals.icu-Kalender (geänderte werden aktualisiert, gestrichene entfernt). intervals.icu schickt jeweils die nächsten 7 Tage an Zwift; dort findest du sie unter Trainings → Custom Workouts. Achte darauf, dass die FTP in Zwift und intervals.icu übereinstimmt.

Tipp für den iPhone-Kalender: In intervals.icu unter Settings die iCal-Adresse des Kalenders kopieren und auf dem iPhone unter Einstellungen → Kalender → Accounts → Account hinzufügen → Andere → Kalenderabo hinzufügen einfügen. Dann aktualisieren sich die Termine automatisch.

Kalenderdatei

Alternative ohne intervals.icu: alle Einheiten als .ics mit Uhrzeit, Erinnerung und Ablauf. Auf dem iPhone „Teilen → Kalender“ bzw. die Datei öffnen und „Alle hinzufügen“.

Einzelne Zwift-Dateien (.zwo) für den PC gibt es in jeder Einheit im Plan.

Sicherung

Alle Daten liegen nur auf diesem Gerät. Mit einer Sicherung überträgst du sie auf ein anderes Gerät.
